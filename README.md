# ESC English

이상한 스피킹 클럽(ESC) 영어 학습 통합 사이트입니다. 기존 두 서비스를 한곳에 모으고 새 기능을 더합니다.

| 모듈 | 원래 저장소 | 내용 |
|---|---|---|
| 🧩 영작 · 단어 나열 | `ESC_SPEAKING` | 한국어 문장을 보고 단어를 탭하거나 **🎤 말해서** 영어 문장 완성 (음성 입력 신규) |
| 📚 단어 공부 | `ESC_WORD` | 학습 카드 + 철자 테스트 |
| ✍️ 빈칸 표현 (신규) | 구글 시트 | 예문 속 표현만 빈칸으로, 10문장씩 진도 · 복습 · 심연 |
| 🔐 로그인 (신규) | — | 카카오/구글 OAuth, 자동 로그인, 내 학습 기록 |

## 현재 상태: UI/UX 프로토타입

- `index.html`, `css/style.css`, `js/app.js` — 모든 화면과 흐름을 눌러 볼 수 있는 정적 프로토타입
- `js/mock-data.js` — 실제 데이터 일부 발췌
- **로그인 · 음성 인식 · 서버 기록 저장은 시뮬레이션**입니다. 실제 구현 사양은 [`docs/기능명세서.md`](docs/기능명세서.md)에 정리되어 있습니다.

### 로컬에서 보기

```bash
python3 -m http.server 8000
# http://localhost:8000 접속 (모바일 화면 크기로 보면 좋아요)
```

- `?inapp=1`을 붙이면 카카오톡 인앱 브라우저일 때의 로그인 시트(Google 비활성 안내)를 볼 수 있습니다.
- 빈칸 학습 진도는 브라우저 `localStorage`에 저장되며, 개발자 도구에서 `esc.proto.*` 키를 지우면 초기화됩니다.
